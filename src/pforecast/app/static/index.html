어떻게 동작하나요? 계통에 상관없이 같은 흐름
  1. 데이터 — 현장 CSV 한 파일. 인코딩·헤더·날짜 표기·상태 문자열은 알아서 정리하고 고친 내역을 보여줍니다.
  2. 변수 — 예측할 값(y) 하나와, 미리 알 수 있는 입력(x: 계획·설정값·예보).
  3. 기간 — 학습 기간과 그 뒤의 검증 기간. 학습 범위 밖 운전조건이 섞이도록 고르면 물리모델과 ML 의 차이가 드러납니다.
  4. 모델·실행 — 계통 모델을 고르고 CSV 컬럼을 모델 변수에 연결. 물리 파라미터를 보정하고 ML(다항·부스팅)과 같은 조건으로 비교합니다.
  5. 검증 결과 — 학습 때 없던 조건에서의 오차, 사용한 방정식·알고리즘 설명.
  6. 미래 예측 — 계획 CSV(또는 최근 패턴을 조정해 만든 계획)를 넣어 예측하고, 설비 상태 변동 폭과 관리기준 초과 시간을 봅니다.

계통 모델이 없으면 모델 만들기에서 컴포넌트를 골라 연결하거나(코드 없음), ML 만으로 비교할 수 있습니다. 계통 구조(무엇이 무엇에 연결되는가)는 데이터에서 유도할 수 없어 사람이 정합니다.

2. 무엇을 예측할까요?

예측할 값(y) 하나와, 그 값을 설명할 입력(x)을 고르세요. 이름을 누르면 시계열이 보입니다.

입력(x)에는 예측하는 시점에 미리 알 수 있는 값만 넣으세요 — 생산계획(가동률·장비 대수), 설정값, 기상 예보 같은 것. 같은 시각에 측정되는 결과값(출구 유량·차압·온도 등)을 넣으면 ‘미래 예측’이 아니라 ‘현재값 추정’이 됩니다 (데이터 누수).

3. 학습 기간과 예측 기간

예측 기간은 반드시 학습이 끝난 뒤여야 합니다. 차트 위를 끌어서 고르거나 날짜를 입력하세요. 규칙에 어긋나는 선택은 자동으로 막습니다.

4. 모델 고르고 실행

물리모델과 ML(다항식·그래디언트 부스팅)을 같은 학습 데이터, 같은 입력으로 학습해 예측 기간에서 비교합니다.

5. 검증 결과

과거의 예측 기간에서 물리모델과 ML 을 비교합니다.

4단계에서 실행하세요.

6. 미래 예측

정답이 없는 미래입니다. 계획(입력 x 의 앞으로 값)을 넣으면 과거 전체로 학습한 모델이 예측합니다. 채점 대신 설비 상태 변동 폭과 학습 범위 밖 여부를 같이 보여줍니다.

모델 만들기

컴포넌트를 고르고 출구 → 입구로 연결하면 계통 모델이 됩니다. 고칠 때마다 방정식·미지수 개수, 연결, 설계점 풀이를 자동으로 검사합니다. 저장하면 4단계에서 고를 수 있습니다.
