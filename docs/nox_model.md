# 배기 스크러버 → 굴뚝 NOx 모델

첫 적용 대상 계통의 물리와 검증 결과입니다.

```
  장비군 4개 ──┐ (지류 덕트)
               ├─► 헤더 ─► 메인 덕트 ─► 습식 스크러버 ─► 유인송풍기 ─► 굴뚝
             ──┘
```

| 장비군 | 대수 | 대당 풍량 | 배기온도 | 상대습도 | 특성 |
|---|---|---|---|---|---|
| DRY (건식식각) | 24 | 220 Nm³/h | 52 ℃ | 40% | NOx 주 발생원 |
| CVD (증착) | 18 | 260 Nm³/h | 61 ℃ | 35% | 퍼지 기저 발생량이 큼 |
| WET (습식세정) | 30 | 160 Nm³/h | 38 ℃ | 85% | NOx 적고 습분 많음 |
| IMP (이온주입) | 8 | 180 Nm³/h | 47 ℃ | 40% | 지류가 가늘다 |

모델 규모: **방정식 174개 / 미지수 174개 / 파라미터 82개**, BLT 15블록(최대 160×160).

---

## 핵심 설계: 유량을 고정하지 않는다

배기원을 "유량 상수"로 두면 팬 성능곡선도 덕트 저항도 결과에 영향을 주지 않습니다.
그러면 현장에서 가장 알고 싶은 질문 — *가동율을 올리면 배기 용량이 모자라지 않나* —
을 모델이 아예 표현하지 못합니다.

그래서 **압력 구동**으로 둡니다. 각 장비의 후드/댐퍼가 저항이고, 룸 압력과 헤더
압력의 차이로 유량이 결정됩니다.

```
p_room − p_header = dp_design · (ρ_ref/ρ) · (ṁ / (n_eff · ṁ_ref))²
n_eff = n_tools · (idle_frac + (1 − idle_frac) · util)
```

병렬 저항이므로 장비가 늘수록 유량이 늘지만, 팬 곡선을 타고 내려가며 **포화**합니다.
이 포화가 외삽 구간의 농도 급등을 만듭니다.

실제로 가동율을 4배(30% → 120%) 올려도 배기 유량은 1.34배밖에 늘지 않습니다.
같은 구간에서 NOx 발생량은 3.2배가 됩니다 — 이 격차가 그대로 농도 상승입니다:

| 가동율 | 굴뚝 유량 | NOx 발생량 | 제거효율 | L/G | 굴뚝 농도 | 대당 배기 |
|---|---|---|---|---|---|---|
| 30% | 10,691 Nm³/h | 456 g/h | 22.8% | 2.64 | 35.1 mg/Sm³ | 5.40 CMM |
| 50% | 11,968 | 679 g/h | 21.7% | 2.36 | 47.3 | 4.86 |
| 80% | 13,281 | 1,013 g/h | 20.8% | 2.13 | 64.4 | 4.16 |
| 100% | 13,882 | 1,235 g/h | 20.4% | 2.04 | 75.5 | 3.77 |
| 120% | 14,338 | 1,458 g/h | 20.2% | 1.98 | 86.6 | 3.44 |

(설계 파라미터 기준. 보정 후 값은 더 높습니다.)

## 지배방정식

### 질량·화학종

추적 화학종은 NOx(NO₂ 환산), H₂O, O₂ 세 가지이고 나머지는 캐리어(N₂)로 묶습니다.
세 가지 모두 필요한 이유가 분명합니다.

* **NOx** — 규제 대상
* **H₂O** — 건조 기준 환산에 필요. 습분이 틀리면 mg/Sm³ 가 통째로 틀어집니다.
* **O₂** — 표준산소 보정에 필요

### 운동량

모든 요소가 `Δp = K·ṁ|ṁ|/ρ` 형태입니다. `K [1/m⁴]` 는 `f·L/(2·D·A²)` 를 하나로
묶은 값이고, 밀도로 나누므로 온도 변화가 압력손실에 자동 반영됩니다.

송풍기는 2차 성능곡선 + 상사법칙:

```
Δp = n² · (c₀ + c₁·(Q/n) + c₂·(Q/n)²) · (ρ/ρ_ref)
```

굴뚝은 통풍력까지 포함합니다: `Δp_draft = (ρ_amb − ρ_gas)·g·H`.
예제 조건에서 25 m 굴뚝이 약 2.6 mmAq 의 흡입을 만듭니다
(굴뚝 입구 압력이 H=0 일 때 +16.7 mmAq, H=25 m 일 때 +14.1 mmAq).

### 에너지

혼합 비엔탈피에 **수증기 잠열을 포함**합니다.

```
h = Σ wᵢ·cpᵢ·(T − T₀) + w_H2O · h_fg,0
```

이게 있어야 스크러버의 증발 냉각이 닫힙니다. 예제 설계점에서 가스는 45.4 ℃ 로
들어가 **36.7 ℃** 로 나오고, 증발수는 0.005 kg/s 입니다.

### 스크러버 제거효율

물질전달 단위수(NTU)에서 옵니다.

```
L/G = Q_liquid / Q_gas
NTU = a · (L/G)^b          (b ≈ 0.55, 물질전달 이론값 0.4~0.8 범위)
η   = η_max · (1 − e^(−NTU))
```

순환수량이 고정된 상태에서 가스량만 늘면 L/G 가 떨어지고 효율이 무너집니다.
**학습 데이터에 고부하가 없으면 ML 은 이 변곡을 결코 알 수 없습니다.**
반면 이 식은 그대로 외삽됩니다.

### 표준상태 환산

현장 TMS 값과 직접 비교하려면 세 보정을 전부 방정식으로 들고 있어야 합니다.

```
C_dry  = C_wet / (1 − y_H2O)
C_corr = C_dry · (21 − O2_ref) / (21 − O2_meas)
```

**표준산소 보정은 기본적으로 끕니다**(`o2_corr = 0`). 팹 배기는 사실상 공기라
O₂ 실측이 20.9% 에 붙어 있고, 여기에 O₂ 보정을 적용하면 분모가 0 에 붙어 발산합니다.
연소시설에 이 컴포넌트를 쓸 때만 `o2_corr=1, O2_ref=0.04` 처럼 켜세요.

(이건 실제로 개발 중에 겪은 문제입니다. 초기 구현에서 O₂ 보정을 무조건 적용했더니
농도가 115,000 mg/Sm³ 로 나왔습니다.)

## 검증

### 합성 데이터

`make_synthetic_data.py` 는 물리 모델을 '진짜 공장'으로 돌리되 파라미터를 설계값에서
일부러 틀어 놓고(현장은 설계대로 지어지지 않습니다), 계측 노이즈·센서 바이어스·
통신 두절 구간을 얹습니다.

숨겨둔 '진짜' 값 (설계값 → 실제):

| 파라미터 | 설계 | 실제 | 사유 |
|---|---|---|---|
| `SRC_DRY.ef_process` | 7.0 mg/s | 8.6 | 레시피 변경 |
| `SRC_DRY.ef_idle` | 0.55 | 0.80 | |
| `SRC_CVD.ef_process` | 5.0 | 4.1 | |
| `SCR.eta_max` | 0.55 | 0.47 | 충전재 열화 |
| `SCR.ntu_a` | 14.0 | 11.0 | |
| `DCT_MAIN.K` | 17.0 | 23.0 | 덕트 오염/퇴적 |
| `SCR.K` | 51.0 | 68.0 | 충전층 막힘 |

### 저부하로만 보정 → 고부하 검증

30일치 5분 데이터(결측 행을 뺀 8,612행)를 가동율로 잘랐습니다.
학습 **util ≤ 0.55** (1,059행) / 검증 **util ≥ 0.62** (6,160행).

| 모델 | 학습 RMSE | 검증(외삽) RMSE | 검증 편향 | 검증 R² |
|---|---|---|---|---|
| 물리모델 | 2.47 mg/Sm³ | **2.52** | −0.33 | 0.919 |
| ML 기준모델(2차 다항) | 2.45 | **2.70** | −0.63 | 0.907 |

계측 노이즈 σ 가 3.0 mg/Sm³ 이므로 물리모델의 검증 오차 2.52 는 **노이즈 수준**입니다.
사실상 외삽 오차가 없습니다.

다만 이 예제는 검증 구간이 학습 구간에서 멀지 않아(가동율 0.55 → 0.62 이상) ML 도
크게 무너지지 않습니다 (+10%). 격차가 벌어지는 것은 증설처럼 **학습 구간에서 변한 적
없는 변수가 바뀔 때**입니다 — [현장형 데이터 테스트](field_test.md)에서 ML 오차가
물리모델의 몇 배로 벌어지는 것을 봅니다.

(이 표는 예제 데이터를 다시 생성한 뒤 재측정한 값입니다. 이전 판의 ML 3.72 는 옛
데이터 기준이라 고쳤습니다.)

### 압력 계통 파라미터는 정확히 복원됨

| 파라미터 | 설계 | 보정 | 진짜 | 오차 | 상대표준오차 |
|---|---|---|---|---|---|
| `DCT_MAIN.K` | 17.0 | 24.42 | 23.0 | +6.2% | 2.5% |
| `SCR.K` | 51.0 | 71.28 | 68.0 | +4.8% | 0.34% |

차압 계측이 따로 있으므로 잘 결정됩니다. 이 값들은 **설비 진단에 그대로 쓸 수
있습니다** — 설계 대비 +40% 안팎은 실제 덕트 오염/충전층 막힘 수준을 의미합니다.

배출계수와 제거효율 상수는 곱으로만 결정되어 개별 값의 상대표준오차가 100%를
넘습니다. 툴이 이를 경고하며, 예측 성능에는 영향이 없습니다.

## 실무 결론 (보정된 모델 기준)

관리기준 100 mg/Sm³ (법정 배출허용기준의 절반, 사내 자체기준) 적용 시:

| 케이스 | 굴뚝 NOx | 대당 배기 | 판정 |
|---|---|---|---|
| 현행 (가동율 80%) | 79.4 mg/Sm³ | 3.91 CMM | 여유 21% |
| 풀가동 100% | 92.9 | 3.53 | 여유 7.1% |
| 증설 +30%, 가동율 80% | 96.9 | 3.21 | 여유 3.1% |
| **증설 +30% + 풀가동** | **114.7** | **2.86** | **기준 초과 14.7%** |
| ㄴ 대책1: 송풍기 110% 증속 | 105.5 | 3.13 | 여전히 초과 5.5% |
| ㄴ 대책2: 순환수 2배 | 108.9 | 2.86 | 여전히 초과 8.9% |
| 에너지절감: 팬 85% 감속 | 91.5 | 3.35 | 동력 −38% (19.6→12.2 kW) |

**증설 +30% 와 풀가동이 겹치면 단일 대책으로는 기준을 못 맞춥니다.** 송풍기 증속과
순환수 증량을 병행하거나, 스크러버 증설/산화제 투입 같은 구조적 대책이 필요합니다.
장비 대당 배기 풍량도 2.86 CMM 으로 후드 포집 한계(3.0)를 밑돕니다.

이 결론은 과거 데이터에 한 번도 나타난 적 없는 조건에 대한 것이며,
**ML 로는 원리적으로 도달할 수 없습니다.**
